# توب ستور - نظام إدارة الحسابات والطلبات (Top Store System)

نظام محاسبي وإداري متكامل وشامل لوساطة الشراء والتسوق الإلكتروني والشحن في اليمن.

## 🚀 المميزات الرئيسية
- إدارة طلبات الشراء والشحن مع حساب العمولات وفروق الصرف بدقة.
- كشوفات حسابات العملاء وإرسال الإشعارات التلقائية عبر واتساب.
- تتبع الشحنات والطرود برقم التتبع وتحديث الحالات.
- إدارة خزائن النقدية والصناديق (ريال يمني، ريال سعودي، دولار أمريكي).
- تقارير أرباح وإحصائيات ورسوم بيانية تفاعلية.
- إمكانية التصدير والاستيراد مع ملفات Excel بنقرة واحدة.
- دعم كامل للغة العربية والعمل دون الحاجة لتهيئة معقدة.

## 🛠️ متطلبات التشغيل والنشر
- **Node.js**: إصدار 18 أو أحدث.
- **التثبيت**: `npm install`
- **البناء للنشر (Build)**: `npm run build`
- **التشغيل المحلي**: `npm run dev`

## 🌐 النشر على Vercel أو Netlify
المشروع مهيأ تلقائياً للعمل بنسبة 100% مع:
- **Vercel**: يحتوي على `vercel.json` لإعادة التوجيه التلقائي.
- **Netlify**: يحتوي على ملف التوجيه `_redirects` داخل مجلد `public`.
